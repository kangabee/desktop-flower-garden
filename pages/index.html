Desktop Flower Garden

바탕화면 구석에서 하루 동안 조용히 꽃을 피우는 작은 도트 정원.
다 핀 꽃은 도감에 모으고, 링크 하나로 친구에게 씨앗을 선물해요.

macOS · Apple 칩 M1 · M2 · M3 · M4 … macOS · Intel 칩 Windows 64비트 · ARM 지원

모든 버전 보기

처음 열 때 경고가 나오면

  • macOS: dmg 를 열어 앱을 Applications 로 옮긴 뒤 실행 → 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안 아래의 "그래도 열기".
  • Windows: 파란 "PC 보호" 창에서 추가 정보 → 실행.
개인이 만든 앱이라 Apple·Microsoft 유료 인증을 받지 않아 나오는 경고예요.

이렇게 써요

  1. 실행하면 화면 오른쪽 아래에 화분이 생겨요. 랜덤 씨앗이 24시간 동안 천천히 자라요.
  2. 화분을 클릭하면 🎵 노래 · 💧 물 · ☀ 햇빛 · 🌿 비료로 돌볼 수 있어요.
  3. 꽃 60종을 대륙별 도감에 모아요. 무궁화·국화 같은 나라꽃은 국기가 붙은 전설 꽃이고, 필 때 반짝반짝 빛나요.
  4. 꽃이 피면 도감에 모이고, 선물하기로 링크를 보내면 친구도 같은 꽃을 키울 수 있어요.

업데이트 기록

v0.5.0 최신 2026.10.26

  • 화분 선반: 꽃을 5종 모으면 화분이 2개, 15종이면 3개로 늘어나 여러 꽃을 함께 키울 수 있어요.
  • 방문객: 씨앗이 자라는 동안 나비 · 꿀벌 · 무당벌레 · 참새 · 반딧불이(밤) · 무지개나비가 찾아와요. 눌러 주면 성장 앞당기기, 희귀 씨앗 확률 업, 보너스 씨앗 같은 선물을 줘요.
  • 날씨 (선택): 도시를 고르면 실제 날씨가 화분에 와요. 비 오는 날엔 물 걱정이 없고, 비가 그친 뒤 해가 나면 1시간 동안 무지개(성장 ×2)가 떠요.
  • 화분 꾸미기: 대륙의 꽃을 모두 모으면 청자 · 델프트 블루 · 탈라베라 · 산호 · 짚 바구니 화분이, 전설 꽃 3종이면 황금 화분이 열려요.
  • 계절 한정 꽃 4종: 겹벚꽃(봄) · 능소화(여름) · 구절초(가을) · 포인세티아(12월) — 그 계절에만 씨앗으로 나와요. 모두 64종.
  • 설정: 효과음 끄기 · 화분 크기(작게/보통/크게) · 움직임 줄이기, 정원 백업 내보내기 · 불러오기.
  • 도감을 등급순(전설 → 희귀 → 흔함)으로 정리하고 도감 번호를 붙였어요. 도감 창에 방문객 · 꾸미기 · 설정 탭 추가.
  • 비료를 줄 때 앱이 멈추던 문제, 도감 칸의 반짝임이 늘어나 보이던 문제를 고쳤어요.

v0.4.1 2026.10.23

  • Windows 자동 업데이트: 새 버전을 알아서 받아 두었다가, 앱을 다시 시작하면 적용돼요.
  • Mac 새 버전 알림: 새 버전이 나오면 화분 말풍선으로 알려 주고, 우클릭 메뉴에서 바로 다운로드 페이지를 열 수 있어요.
  • 이번 버전을 한 번만 직접 설치하면, 다음 버전부터 위 방식으로 업데이트돼요.

v0.4.0 2026.10.23

  • 4개 언어 지원: 한국어 · English · 日本語 · 简体中文. 컴퓨터 언어를 자동으로 따라가고, 화분 우클릭 → 🌐 언어에서 직접 고를 수도 있어요. 선물 링크는 받는 사람의 언어로 보여요.
  • 새 꽃 29종 추가 → 모두 60종 (흔함 24 · 희귀 22 · 전설 14). 오세아니아 · 아프리카 꽃이 늘었어요.
  • 전설 꽃 반짝임: 필 때 별이 터지고, 화분과 도감에서 계속 반짝반짝 빛나요.
  • Windows 설치 파일 하나로 64비트 · ARM PC 모두 지원 (32비트는 지원하지 않아요).

v0.3.0 2026.10.22

  • 새 꽃 17종 추가 → 모두 31종. 꽃말이 따뜻한 꽃만 골랐어요.
  • 무궁화 · 모란 · 매화 · 국화 · 히비스커스 · 붓꽃 · 수레국화 · 카네이션 · 달리아 · 골든 와틀 · 킹 프로테아 등 나라꽃은 전설 등급, 도감 · 말풍선 · 선물 카드에 도트 국기가 붙어요.
  • 개나리 · 진달래 · 미선나무 · 금강초롱꽃 등 한국의 꽃과 캐모마일 · 블루보넷 추가.
  • 비료 추가: 한 번에 1시간 빨리 자라요 (12시간에 한 번, 햇빛이 켜져 있을 땐 사용 불가).
  • 도감을 대륙별(아시아 · 유럽 · 아메리카 · 오세아니아 · 아프리카 · 환상의 꽃)로 나누고 대륙마다 모은 개수를 보여줘요.

v0.2.0 2026.10.22

  • 성장 방식을 하나로: 씨앗을 심고 실제 시간 24시간이면 꽃이 펴요. 앱을 꺼 두거나 컴퓨터를 재워도 시간은 흘러가요.
  • 근무 시간 / 실제 시간 / 데모 모드 선택을 없앴어요. 키우던 꽃은 새 방식으로 이어서 자라요.

v0.1.0 첫 공개 2026.10.22

  • 바탕화면 위에 화분만 떠 있는 투명 도트 위젯 (빈 곳 클릭은 아래 앱으로 그대로 통과).
  • 랜덤 씨앗 14종 · 희귀도 3단계, 씨앗 → 새싹 → 줄기 → 꽃봉오리 → 만개.
  • 돌봄: 🎵 노래 · 💧 물 · ☀ 햇빛 부스터(×1.1), 가끔 꽃이 원하는 걸 들어주면 더 빨리 자라요.
  • 꽃 도감과 키운 기록.
  • 선물 링크: 편지를 써서 보내면 받은 사람이 씨앗 받기 한 번으로 같은 꽃을 키워요.
