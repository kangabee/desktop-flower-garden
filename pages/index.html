Desktop Flower Garden

바탕화면 구석에서 하루 동안 조용히 꽃을 피우는 작은 도트 정원.
다 핀 꽃은 도감에 모으고, 링크 하나로 친구에게 씨앗을 선물해요.

macOS · Apple 칩 M1 · M2 · M3 · M4 … macOS · Intel 칩 Windows

모든 버전 보기

처음 열 때 경고가 나오면

  • macOS: dmg 를 열어 앱을 Applications 로 옮긴 뒤 실행 → 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안 아래의 "그래도 열기".
  • Windows: 파란 "PC 보호" 창에서 추가 정보 → 실행.
개인이 만든 앱이라 Apple·Microsoft 유료 인증을 받지 않아 나오는 경고예요.

이렇게 써요

  1. 실행하면 화면 오른쪽 아래에 화분이 생겨요. 랜덤 씨앗이 24시간 동안 천천히 자라요.
  2. 화분을 클릭하면 🎵 노래 · 💧 물 · ☀ 햇빛으로 돌볼 수 있어요.
  3. 꽃이 피면 도감에 모이고, 선물하기로 링크를 보내면 친구도 같은 꽃을 키울 수 있어요.
