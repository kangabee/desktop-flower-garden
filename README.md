# 🌸 Desktop Flower Garden

바탕화면 구석에서 조용히 꽃을 피우는 작은 도트 정원이에요.
랜덤 씨앗이 하루(실제 시간 24시간) 동안 천천히 자라고, 다 핀 꽃은 도감에 모으거나 편지와 함께 친구에게 선물할 수 있어요.

---

## 설치하기

### macOS

1. 내 Mac에 맞는 파일을 받아요.
   - **Apple 칩(M1·M2·M3·M4…)** → `DesktopFlowerGarden-x.x.x-mac-arm64.dmg`
   - **Intel 칩** → `DesktopFlowerGarden-x.x.x-mac-x64.dmg`
   - 잘 모르겠다면: 화면 왼쪽 위  → **이 Mac에 관하여** 에서 "칩" 또는 "프로세서" 확인
2. dmg 를 열고 **Desktop Flower Garden** 아이콘을 **Applications** 폴더로 끌어다 놓아요.
3. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 (Apple 유료 인증을 받지 않은 개인 앱이라 그래요):
   - **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 아래쪽 **"그래도 열기"** 를 누르고, 다시 앱을 열어요.
   - (macOS 14 이하) 앱 아이콘을 **우클릭 → 열기** 해도 돼요.
   - "손상되었기 때문에 열 수 없습니다" 가 나오면 터미널에서 한 번만 실행해 주세요:
     ```bash
     xattr -cr "/Applications/Desktop Flower Garden.app"
     ```

### Windows

1. `DesktopFlowerGarden-win-setup.exe` 를 받아 실행하면 바로 설치되고 바탕화면에 아이콘이 생겨요.
   64비트 · ARM(스냅드래곤 노트북 등) PC 모두 이 파일 하나로 설치돼요. (32비트 Windows는 지원하지 않아요)
2. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 눌러요.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 정원 열기 | 앱 아이콘 더블클릭 → 화면 **오른쪽 아래**에 화분이 나타나요 (Dock·작업표시줄에는 안 보여요) |
| 진행 상황 보기 | 화분에 마우스를 올리면 말풍선 |
| 돌봐주기 | 화분 **클릭** → 🎵 노래 · 💧 물 (각각 3시간마다 성장 +1%) |
| 햇빛 부스터 | 화분 클릭 → ☀ 를 켜 두면 끌 때까지 **×1.1 빨리** 자라요. 대신 흙이 빨리 말라 물을 자주 원하고, **목마른 동안엔 부스터가 멈춰요** |
| 비료 | 화분 클릭 → 🌿 비료를 주면 **1시간** 빨리 자라요. 12시간에 한 번, 햇빛이 켜져 있을 땐 쓸 수 없어요 |
| 꽃의 바람 | 가끔 화분 옆에 💧/☀/🎵 생각 풍선이 떠요 ("이 꽃은 물을 원하는 것 같아요"). 들어주면 +2% |
| 새 꽃 키우기 | 꽃이 다 피면 화분 클릭 → 🌱 (또는 우클릭 → 새 씨앗 심기). 핀 꽃은 도감에 남아요 |
| 자리 옮기기 | 화분을 끌어다 놓기 (위치 기억) |
| 설정 · 종료 | 화분 **우클릭** 또는 메뉴 막대/트레이의 🌸 아이콘 |
| 도감 · 선물 | 돌봄 메뉴의 📖, 또는 앱 아이콘을 한 번 더 실행 |
| 씨앗 선물 | 도감 → 꽃 → **선물하기** → **선물 링크 복사** 후 메신저로 보내요. 받은 사람은 링크에서 **씨앗 받기** 한 번이면 같은 꽃이 화분에 심어져요 |
| 언어 | 한국어 · English · 日本語 · 简体中文. 컴퓨터 언어를 자동으로 따르고, 우클릭 메뉴 → **🌐 언어**에서 바꿀 수 있어요 |
| 컴퓨터 켤 때 자동 실행 | 우클릭 메뉴 → **로그인 시 자동으로 정원 열기** |

**성장 시간**: 씨앗을 심은 뒤 **실제 시간 24시간**이면 꽃이 펴요. 앱을 꺼 두거나 컴퓨터를 재워도 시간은 흘러가요.
돌봄(노래·물 +1%, 꽃이 원할 때 들어주면 +2%)과 햇빛 부스터(×1.1)로 조금 더 빨리 피울 수 있어요.

**꽃 선물하기**: 도감에서 꽃을 고르고 **선물하기** → 받는 사람·편지·보내는 사람을 쓰고 **선물 링크 복사**.
받은 사람은 링크에서 카드를 보고 **씨앗 받기** 를 누르면 앱이 열리며 같은 꽃이 심어져요
(지금 키우는 꽃이 아직 자라는 중이면 다음 차례로 예약돼요). 코드를 복사하거나 입력할 일은 없어요.
브라우저가 "Desktop Flower Garden 을 열까요?" 라고 물으면 허용을 눌러 주세요.

**도감**: 꽃 60종(흔함 24 · 희귀 22 · 전설 14)이 대륙별(아시아 · 유럽 · 아메리카 · 오세아니아 · 아프리카 · 환상의 꽃)로 나뉘어 있어요.
무궁화·모란·매화·국화처럼 **나라를 대표하는 꽃은 전설 등급**이고, 도감과 선물 카드에 그 나라 국기가 붙어요.
전설 꽃은 필 때 별이 터지고, 화분과 도감에서 계속 반짝여요.

**씨앗**: 무슨 꽃인지는 비밀이지만, 씨앗 색으로 희귀도를 짐작할 수 있어요 — 갈색(흔함) · 푸른 윤기(희귀) · 금빛 반짝임(전설).

### 업데이트
- **Windows**: 새 버전을 알아서 받아 두었다가, 앱을 껐다 켜면 적용돼요. 우클릭 메뉴의 **✨ 다시 시작해서 업데이트** 로 바로 적용할 수도 있어요.
- **macOS**: 새 버전이 나오면 화분 말풍선으로 알려 주고, 우클릭 메뉴의 **✨ 새 버전 받기** 가 다운로드 페이지를 열어요. 받은 dmg 로 덮어 설치하면 정원 기록은 그대로예요.
  (Mac 완전 자동 업데이트는 Apple 개발자 인증서가 있어야 해서 지금은 알림 방식이에요)
- 새 버전 확인은 GitHub Releases 에서 버전 번호만 읽어요. 별도 서버나 개인 정보 전송은 없어요.

### 지우기
- macOS: Applications 에서 앱을 휴지통으로. 정원 기록까지 지우려면 `~/Library/Application Support/desktop-flower-garden` 폴더도 삭제.
- Windows: 설정 → 앱 → Desktop Flower Garden 제거. 기록은 `%APPDATA%\desktop-flower-garden`.

## 개발자용

```bash
npm install        # 의존성 설치
npm run dev        # 개발 실행 (Vite + Electron)
npm run icon       # build/icon.png 다시 생성
npm run dist:mac   # release/ 에 Mac dmg (arm64·x64)
npm run dist:win   # release/ 에 Windows 설치 파일
```

- `http://localhost:5173/#gallery` — 꽃 14종 × 성장 단계 스프라이트 미리보기
- **배포 자동화**: GitHub 저장소에 올린 뒤 `git tag v0.2.0 && git push origin v0.2.0` 하면
  `.github/workflows/release.yml` 이 Mac·Windows 설치 파일을 만들어 Releases 페이지에 올려요.
  사람들에게는 Releases 페이지 링크 하나만 알려주면 돼요.
- **선물 링크**: `dist/card.html` 을 GitHub Pages 등에 올리고 `VITE_SHARE_BASE_URL` 을 설정해야
  "선물 링크 복사" 버튼이 켜져요 (`.env.example` 참고). 링크의 "씨앗 받기"는 앱 링크(`flowergarden://`)로 앱을 연다.
- **씨앗 검증**: 설치마다 숨은 정원 ID, 링크마다 숨은 씨앗 ID가 있어요. 같은 링크를 한 정원에서 두 번 받거나,
  내가 보낸 씨앗을 내가 받는 건 막혀요. 서버가 없어서 링크가 여러 사람에게 퍼지면 각자 한 번씩은 받을 수 있어요.
- 서명: 지금은 ad-hoc 서명이라 첫 실행 경고가 나와요. 경고 없이 배포하려면 Apple Developer 인증서(연 $99)로
  서명·공증하거나 Windows 코드 서명 인증서가 필요해요.
